# 社交障碍如何毁了你一切

最困难的问题是：如何开头

---

在社区里，往往很容易发现对方轻而易举地拿下属于自己的海外支付/电话方式，海外支付/账号接码难题于他们而言好像完全不存在。

甚至是 AI 模型也总是可以找到各种各样的 API 中转站。

在社区里，人们往往熟练使用闲鱼等网购平台，与店家或客服激烈的对轰来得到诱人的低价，完美的成品。

他们拥有很强的对线能力，完全没有任何负担，也完全不用担心什么事情，得来的结果往往也十分稳定。

好像成功与陌生人交流于他们而言就像呼吸一样自然。

...

眼馋海外语言模型能力？分分钟拿下使用方案。

需要交谈才可解决的问题？在计划内，完全没事。

他们预估对话内容的能力也很强，开头的勇气也很强大。

...

很多理论知识是完全可以啃文档得来，但实际经验呢？

靠网络搜寻，内容农场成功得到了新的客人。

...

为什么你的经历和几乎所有人相比都是偏的？

自己好像也有不错的社交网络，但真正能建立联系并对自己有帮助的似乎很少。

虽然交朋友只为了利益可能有些短浅，但是现实中有很多人的超乎众人的能力就是通过朋友经验分享与指引来一步步达成...?

这本身就是悖论...

很期待他人的观点，但是，真的有吗？

---

于是无比羡慕周边的几乎所有人。

但你自己“已经落后别人一大截了”的状态只会让事态更加恶化。
