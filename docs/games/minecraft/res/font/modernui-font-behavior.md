# Modern UI 默认字体行为与选项参考

> 以下演示使用的配置
> - Minecraft - 26.1.2
> - Fabric
> - Modern UI - v3.13.0.5 - 舟方日明
> - 资源包 - 杼榅材质 Caerula Arbor Pre#1+ (Calmira Arbor Dev 260719)
