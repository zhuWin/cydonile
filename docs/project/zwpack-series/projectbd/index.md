## 一、什么是 戊边漫划 Project BD 

![pasted-20260926130921](/assets/docres/project/zwpack-series/projectbd/pasted-20260926130921.webp)

一个实验性 Minecraft 多功能资源包实践。从 1.8 PvP 为起点，多版本傻瓜式一站式融合。

自 Cydonia Blue CALMiRA Arbor Pre#4 开始启用中文名称“戊边漫划”，结束"PROJECT ZWPACK 杼榅材质”宽泛代指该特定项目引发的误会。“杼榅材质”将延伸所有由 Mizukoud 杼榅推出的纹理包/资源包系列。

常规版本，在一个包体内实现了多个版本的兼容性的同时尝试努力确保小巧。

ERROR422 版本，兼容 1.5.2 以下版本，为旧版本提供优化。

Lite 版本，1.8 支持 only。挑战体积极限，曾取得了 压缩到 9MiB 以内的记录。但已经许久没有维护了。

它可以是：

- 很棒的 PvP 材质包
- 现代的日常用途美化包
- 十分创人的 Meme 集合
- 关心您的灵车版本
- 多功能资源包模板，作为起点

资源包基于 Sphax PureBDcraft 1.8.4 并包含以下内容：

- **PureBDcraft 64x version 1.14, 1.15, 1.16, 1.17, 1.18, 1.19r1, 1.19r3, 1.20r4, 1.21r6, 26.1r1**
- **VanillaBDcraft 64x version 1.19, 1.21**
- [Yuruze](https://www.planetminecraft.com/member/yuruze/)'s Clouds and Planets Overlay - 微调版本，计划于未来重做天空纹理，目标模仿 maimai PRiSM 背景风格。
- ZWPACK Fonts，使用修改版半糖奶茶 BTNC-ZWPACK (添加字符“榅”)，舟方日明 Sthginkra 和来源不明但常见于 PvP 材质中的英文字体
- Material Icons & Symbols
- 间接或直接来自《明日方舟》《舞萌DX》解包的内容

项目的目标和愿景：

- 作为多功能资源包模板，为您的新项目实现一个不错的起步，功能模组的测试平台
- 足够恰当且创人的内容元素聚合
- 通过资源复用和图像压缩，在保证质量和体积的前提实现一个包兼容足够多的版本
- 试着与前沿同步，使用前沿功能，同时保证重要低版本兼容~~并对着 Mojang 破口大骂~~

在发展流程，我们使用了多种方式来达成我们的目标。

- 资源复用：例如，OptiFine 自定义天空 1.6-1.12 和 1.13+ 使用相同的纹理文件
- 图像压缩：虽然方式存在争议，但是有人真的刻意去看用不到这么多颜色的某些元素吗
- 多余文件移除：有些资源包居然会把 Thumbs.db 和 .DS_Store 打包进去吗，那很好笑了
- 邪门兼容：反正已经同时兼容了，对吧
- 灵车环境：在 v2.2 之前，没有采用更高分辨率的自定义天空原因是我的环境的确炸了。

但是，发展到今天，我们的实现方式在某些情况也的确存在不便。

### 缺陷一 - 困于体积优化而难以增加新功能

有趣的内容和更多的功能是需要空间支持的，但我们也不可能无限压缩一个游戏纹理包。

对包体体积的考量导致增加新的功能时心理负担和实际工作量大大增加。

正在进行的内容独立为这些特定功能的全新发展提供了路径。现在可以放心按照该子内容的主题进一步发展，无需顾虑体积问题和与现有包体的功能整合与主题统一。

例如 Pslo4MC 也开始考虑对模组的支持，但不可能所有人都会在使用 戊边漫划 时用到 伪本地化语言，其实反而是无关紧要的功能。

起初只是很简单的功能，随着迭代发展和更多复杂模组的支持，内容快速膨胀。

自 2025 年 11 月 Cydonia Blue CALMiRA Arbor Pre#3 开始，戊边漫划内置的伪本地化 仅保留原版内容和部分 UI 关键模组的支持，除非必要否则不再添加新的模组支持。

在同时，我们宣布了 Pslo4MC Plus，2026 年 2 月 Alpha #8  CALMiRA PLUS 增加了新的谷歌样式伪本地化语言（`en_XA`）以及更多的模组支持，独立包的体积自此可以放心扩大。

![pasted-20260820214123](/assets/docres/project/zwpack-series/projectbd/pasted-20260820214123.webp)

再者，[Endfield Update Screen](https://modrinth.com/resourcepack/endfield) 原是 戊边漫划 的主菜单背景 reflesh 计划中的一部分，但实际独立拿出来更合适。

### 缺陷二 - 许可证问题
要分发 戊边漫划 PROJECT BD，这将是永远绕不过的坎。

抛开 BDcraft，有别的元素也可能增加复杂性。

因为我的意向是将 PROJECT BD 作为纯粹我自己使用的魔改集合，并没有考虑推广后会发生什么，所以塞了许多专有但个人喜欢的内容

目前正在使用的“半糖奶茶”字体是一种专有字体。很难说在公开场合以各种身份使用这种字体会发生什么事情。

可能会替换为名为“舟方日明”的无衬线字体，但是体积问题很难在目前的限制里使用。

很不幸，这是为了做近乎邪门的多版本兼容所牺牲的优雅性。尤其是在 1.13 以上版本，有许多元素的布局在同一个文件名已经发生了重大变化。同时兼容在某些情况是不可能的。

不同版本,不同模组对于纹理文件的处理方式不同，诸如对 Alpha 透明度的支持可能完全不一致。在 UI 贴图方面会很烦人。您可能会担心您精心调好的纹理贴图在旧版本下 messed up。
