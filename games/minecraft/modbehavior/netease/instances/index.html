    实例版本¶

    约 1648 个字 34 行代码 21 张图片 预计阅读时间 6 分钟

    测试时间：2026.8.28

    网易已经砍掉了部分可以在单人模式选择的版本

    1.21所有子版

    现在是分阶段下载。

    以 1.7.10 为例，首先下载目录名为 1.7.10-Forge10.13.4.1558-1.7.10 的实例，并在首次启动时再下载安装目录名为 1.7.10 的实例

    1.11.2 也是如此

    1.14.3 开始过去网易的多个模组合一，模组 ID netease_official，提供传统的 depart 资源目录，截至 26 年 7 月 1.21.10 仍然保持 2018 年左右的网易版 Mojang Logo 界面

    部分版本启动使用 quickplay 机制，启动时由启动器自动更改，文件名保持不变， 1717576855170 含义为 unix ms 2024-06-05 16:40:55.170

    1.20.6 没有使用

    在 1.19.2 及之前，使用 inheritsFrom 机制，但使用单独的实例目录

    自 1.14.3/1.16.4 以来，网易的 Minecraft 启动器已经采用了预先准备的启动参数来启动游戏，而不是手动处理原版 JSON

    网易采用预先准备的启动参数，在实例的 JSON 文件中添加 jvm_arguments和parameter_arguments 键 既然网易已经想好只会提供特定版本，这似乎没什么问题，还可以加快本来就死慢的启动速度，但他们似乎并没有检查启动参数里面有什么。

    自 Minecraft 的某一版本开始，Mojang 在实例 JSON 中允许第三方启动器更改启动参数来声明自己的启动器品牌和版本，并于 1.21 左右的某个版本将启动器名称写入崩溃报告中。

    ...于是自 1.21.8 开始，网易换用了 HMCL 来为他们的中国版生成启动参数，并原封不动的把 HMCL 名称和 HMCL 的版本写进了预构建的启动参数中

    现在最新的网易 Java 版发生崩溃时崩溃报告成功地把锅甩到了 HMCL 上面。

    1.21.8开始 使用独立的 C:\netease_minecraft_neoforge，不再使用 C:\MCLDownload\Game\.minecraft\ (<HKEY_CURRENT_USER\Software\Netease\MCLauncher\DownloadPath> \Game\.minecraft) 该路径无法通过注册表修改。

    如果通过 EC 服务器下载 1.21.8 客户端 会显示 NeoForge earlyloading 窗口

    如果通过单人世界下载 1.21.8 客户端不会显示 earlyloading 窗口，但 1.21.10 会。

    修复客户端安装时客户端下载百分比显示出现问题

    1.21.8,1.21.10 启动时需要关闭网络代理，否则客户端模组会认为启动器已经关闭，开始试图关闭游戏

    关闭游戏的例程存在问题，会产生一系列的错误并最终崩溃，可能会误报为 GLFW 无法获取平台信息的问题 游戏崩溃可能无法结束 Java 进程，需要手动干预。

    1.21.8/1.21.10 网易启动器端创建世界“实验性内容”仍然是 “收纳袋”等。

    1.21.8,1.21.10 无法正常自动进入世界生成而卡进主界面

    但是从其他界面返回主界面或者进入服务器列表仍然会导致游戏自动退出。

    1.21，1.21.8和1.21.10，包括布吉岛1.20.1 设置界面中，语言等选项不再被移除。仅此。

    根据日志，账户类型仍为“msa”，Realms 会返回 401， Mojang Auth 相关配置仍然使用 Mojang 验证服务器

    暂停菜单中社交、bug反馈、开放到局域网、模组等选项被移除

    但仍可使用 /publish 命令开放到局域网和 P 键使用服务器社交菜单

    此时国际版本使用微软账户登录仍可试图进入该局域网会话并顺利通过连接时的账号验证，并被进入局域网会话后的网易模组验证立刻赶下线
